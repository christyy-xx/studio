# **App Name**: HRAi Dashboard

## Core Features:

- Job Post Generator: Textarea to input job descriptions; convert the job description into a structured job post using a LLM tool.
- Candidate List: Display name, resume score and status, filtering and sorting options, fetched from the database.
- AI Interview Results: Show AI interview status, score, feedback summaries. 
- Dynamic Contract Creator: Input name, then dynamically create contract document by augmenting existing documentation with a LLM tool (RAG-based).
- Calendar Timesheet: Table with date, task, duration; synced Gmail/Google Calendar events and includes Sync button.
- Alerts Panel: Stream recent email/Telegram alerts to the dashboard.
- Responsive Layout: Implement a responsive layout that adapts to different screen sizes, ensuring optimal viewing experience on desktops, tablets, and mobile devices.

## Style Guidelines:

- Primary color: Navy blue (#2E3192) for professionalism and trust.
- Background color: Light gray (#F0F2F5) for a clean, modern look.
- Accent color: Teal (#00A36C) for highlighting key elements and CTAs.
- Body and headline font: 'Inter' sans-serif for a modern, objective feel.
- Use simple, professional icons from a library like FontAwesome or Material Icons.
- Card-based design with consistent padding and spacing to maintain a clean, organized layout.
- Subtle transitions and animations (e.g., fade-in effects) to enhance user experience without being distracting.
